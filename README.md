🛒 Ecommerce API
A powerful and scalable E-commerce Backend API built using NestJS, TypeScript, and PostgreSQL.
🚀 Features
🔐 Authentication & Authorization (JWT)
👤 User Management
🛍️ Product Management
🧾 Orders System
🛒 Cart System
⭐️ Reviews System
📧 Email Service
📦 File Upload (Multer)
🛠️ Tech Stack
Backend: NestJS
Language: TypeScript
Database: PostgreSQL
ORM: TypeORM
Authentication: JWT
File Upload: Multer
📁 Project Structure
src/ ├── auth/ ├── users/ ├── products/ ├── categories/ ├── orders/ ├── cart/ ├── review/ ├── mail/ ├── config/
⚙️ Installation
git clone https://github.com/AbdelshafyAli00/ecommerce_api.git cd ecommerce-api npm install 
▶️ Running the App
npm run start:dev
