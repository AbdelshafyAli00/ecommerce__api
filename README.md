🛒 Ecommerce API

A scalable E-commerce Backend API built with NestJS, TypeScript, and MongoDB.

---

🚀 Features

- 🔐 Authentication (JWT)
- 👤 Users Management
- 🛍️ Products & Categories
- 🛒 Cart System
- 📦 Orders System
- ⭐ Reviews
- 📧 Email إرسال
- 📁 File Upload

---

🛠️ Tech Stack

- NestJS
- TypeScript
- MongoDB
- JWT
- Multer

---

⚙️ Installation

git clone https://github.com/AbdelshafyAli00/ecommerce_api.git
cd ecommerce-api
npm install

---

▶️ Run Project

npm run start:dev

---

🔐 Environment Variables

Create ".env" file:

PORT=3000
DB_URI=your_database_url
JWT_SECRET=your_secret
